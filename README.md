# MainCrafts Landing Page

A modern, responsive landing page built using HTML and CSS as part of the MainCrafts Full Stack Web Development Internship - Task 1.

## Features

* Responsive Navigation Bar
* Dropdown Menu
* Hero Section with Call-to-Action Button
* Features Section with Icons
* Modern UI Design
* Footer Section
* Mobile Responsive Layout

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome Icons

## Project Structure

MC_Landing_Page/
├── index.html
├── style.css
└── README.md

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any web browser.
